# [Frökenhag] — website

This is a React single-page website powered by Vite. The page components and content are in `src/App.jsx`; styles remain in `styles.css`.

## Run locally

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev` and open the address printed in the terminal.

## Customise before launch

Replace the placeholder brand name, `[DITT NAMN]`, the about text, material image slots, email address, Instagram handle, and SnapWidget URL in `src/App.jsx`. Put image files in `images/` and reference them with paths such as `/images/your-photo.jpg`.

## Production build

Run `npm run build`. The deployable files are written to `dist/`.
